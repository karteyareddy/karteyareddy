<a href="https://github.com/karteyareddy/Q-TrafficX"><picture><source media="(max-width: 700px) and (prefers-color-scheme: light)" srcset="assets/sp-p-qtrafficx-m-light.svg"><source media="(max-width: 700px)" srcset="assets/sp-p-qtrafficx-m.svg"><source media="(prefers-color-scheme: light)" srcset="assets/sp-p-qtrafficx-light.svg"><img src="assets/sp-p-qtrafficx.svg" width="100%" alt="Q-TrafficX: weather-aware traffic digital twin optimised with QAOA on Qiskit Aer" /></picture></a>

A simulated network of connected intersections. Rain, flooding, fog, accidents and emergency vehicles reshape traffic demand, and the system rebuilds signal timing as a QUBO problem on each update. That problem is solved with QAOA on a quantum simulator and compared against classical baselines. The repo includes the specs, test suite and an interactive 2D/3D visualiser.
**[Repository →](https://github.com/karteyareddy/Q-TrafficX)**

<a href="https://github.com/karteyareddy/ISL"><picture><source media="(max-width: 700px) and (prefers-color-scheme: light)" srcset="assets/sp-p-signbridge-m-light.svg"><source media="(max-width: 700px)" srcset="assets/sp-p-signbridge-m.svg"><source media="(prefers-color-scheme: light)" srcset="assets/sp-p-signbridge-light.svg"><img src="assets/sp-p-signbridge.svg" width="100%" alt="SignBridge India: Deaf-first Indian Sign Language accessibility network" /></picture></a>

An accessibility network for hospitals, stations and service counters. A QR code at the counter opens phrase cards and offline service packs with no install. Hand and pose landmarks are extracted in the browser with MediaPipe, so frames never leave the device. A FastAPI model only answers above an 85% confidence threshold; below it, the user is routed to visual phrase selection or a human interpreter.
**[Repository →](https://github.com/karteyareddy/ISL)**

<a href="https://github.com/karteyareddy/Whatsapp_Bot"><picture><source media="(max-width: 700px) and (prefers-color-scheme: light)" srcset="assets/sp-p-replywise-m-light.svg"><source media="(max-width: 700px)" srcset="assets/sp-p-replywise-m.svg"><source media="(prefers-color-scheme: light)" srcset="assets/sp-p-replywise-light.svg"><img src="assets/sp-p-replywise.svg" width="100%" alt="ReplyWise Local: local-first WhatsApp CRM with AI-drafted replies and manual approval" /></picture></a>

A local dashboard for WhatsApp that decides whether to reply, drafts what to say, and remembers context per contact. It falls back across Gemini, OpenRouter, Groq and a local provider, and every message waits for a human to approve it.
**[Repository →](https://github.com/karteyareddy/Whatsapp_Bot)**
